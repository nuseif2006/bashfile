Bash Script Generator

A lightweight CLI utility designed to streamline the creation of new Bash scripts by automating boilerplate setup, including shebang insertion and executable permission configuration.

Features
1. Automated Boilerplate: Instantly includes the standard #!/bin/bash shebang.

2. Permission Management: Automatically applies executable permissions (chmod +x) upon creation.

Installation

1. Download the "create" file

2. Give root access

3. Move the file to /usr/local/bin to access it globally

4. Finally type "which create" in your terminal to check whether it exists or not
